# 使い方ヘルプ

このアシスタントは、あらかじめ用意された「スキル」と各種ツールを使って、
複数ステップの作業を自律的に実行するローカルAIエージェントです。

## できること

- **スキルの実行**: 用意されたスキルを使って専門的な作業を行います。ファイルを直接編集するスキルでは、上書き前に自動でバックアップを作成してから保存します。
- **Office文書の作成・編集・読み取り**: Word/Excel/PowerPointの新規作成、既存ファイルの内容確認、編集（検索置換・書式変更・グラフ/画像の追加など）に対応しています。Excelでは、マクロ（VBA）コードの読み込み・追加・上書き・削除・実行にも対応しています。
- **実行計画の提示・承認**: 複数ステップの作業では、着手前にチェックリスト形式の計画が提示されます。内容を確認し、承認してから実行が進みます。
- **スクリプト・コードの実行**: スキルに含まれるスクリプトや、その場で生成したPythonコードを実行できます。原則として実行前に確認メッセージが表示されます（計画承認後はまとめて進みます）。時間のかかる処理はバックグラウンドで実行し、完了を待たずに他のやり取りを続けられます。
- **画像・ファイルの読み込みと提示**: 画像ファイルの内容を確認・説明できるほか、作成・加工したファイルをダウンロードボタンとして提示したり、画像をその場でプレビュー表示したりできます。
- **永続メモリー**: 会話をまたいで引き継ぎたい情報（ユーザー情報・フィードバック・プロジェクトの状況・参考情報）を記憶し、次回以降の会話に活用します。「覚えておいて」と伝えれば保存します。
- **タスクの委譲**: 独立した調査や下調べは、別のエージェントへ委譲して効率的に処理する場合があります。
- **外部ツールとの連携**: 設定されている場合、MCPサーバー経由で外部の追加ツールを利用できます。

## 使い方のコツ

- 作業ディレクトリはメッセージ入力欄にあるフォルダアイコンから指定できます（未指定の場合は既定値が使われます）。
- チャット開始時に表示される定型文ボタンをクリックすると、その内容がそのまま送信されて作業が始まります。
- 要求が曖昧な場合は、こちらから確認の質問をすることがあります。
- スクリプトやコードの実行前に表示される確認メッセージは、内容を確認した上で許可/拒否を選んでください。
