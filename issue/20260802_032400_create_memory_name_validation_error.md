# create_memory で日本語名がバリデーションエラーで拒否された

- **区分**: バグ
- **検知日時**: 2026-08-02 03:24:00
- **対象ログファイル**: data/logs/app_20260802_03.log

## 経緯

`create_memory` ツールで永続メモリーの作成を試みた際、memory name に
日本語を含む値（`IMG_2221-お弁当作りのヒント_肉の冷凍保存`）が指定されたが、
バリデーションルールにより拒否された。

エラーメッセージ: 「name は英数字・ハイフン・アンダースコアのみ、64文字以内で指定してください」

LLMは日本語を含むmemory nameを自動生成していたが、ツール側が英数字・ハイフン・
アンダースコアのみに制限しているため、メモリーの作成に失敗した。

## ログ引用

```
2026-08-02 03:23:33,663 WARNING src.tools: tool_result: name=create_memory content='エラー: name は英数字・ハイフン・アンダースコアのみ、64文字以内で指定してください: IMG_2221-お弁当作りのヒント_肉の冷凍保存'
```

## 推定原因

`create_memory` ツールの name バリデーションが ASCII 文字のみに制限されており、
日本語（全角文字）を許可していない。LLMは日本語を含むmemory nameを生成する可能性がある
ため、バリデーションルールかLLMの生成ロジックのどちらかが修正が必要。
