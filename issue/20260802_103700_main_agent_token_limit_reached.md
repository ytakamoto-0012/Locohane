# メインエージェントのトークン使用量が閾値に達し、引継ぎプロンプトの生成で終了

- **区分**: 問題点
- **検知日時**: 2026-08-02 10:37:03
- **対象ログファイル**: data/logs/app_20260802_10.log

## 経緯

画像ファイルの一覧取得とmdファイルの既存チェックを行うタスク中、
メインエージェントのトークン使用量が閾値(81920)に到達(93541トークン)。
`src.main_token_guard` がWARNINGを出力し、その後LLMは「ユーザーへの
状況報告」と「新しいチャットで再開するための引継ぎプロンプト」を
生成して安全に終了した。

## ログ引用

```
2026-08-02 10:37:03,713 WARNING src.main_token_guard: メインエージェントのトークン使用量が閾値(81920)に達しました(直近の応答: 93541トークン)。引継ぎプロンプトの生成を促します
```

## 推定原因

画像ファイル297件の一覧取得とmdファイル280件の既存チェックで
コンテキストが極端に肥大化した。`config.ini` の
`[graph].token_guard_soft_threshold` (81920) を超えたため、
トークンガードが発動した。
