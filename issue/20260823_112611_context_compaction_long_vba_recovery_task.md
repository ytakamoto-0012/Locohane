# 会話履歴圧縮が発火（長時間のVBAプロジェクト復旧タスクでcumulative_tokensが閾値到達）

- **区分**: 改善点
- **検知日時**: 2026-08-23 11:26:11

- **対象ログファイル**: data/logs/app_20260823_104959.log

## 経緯

前々サイクルのVBAプロジェクト消失（[issue/20260823_110242](20260823_110242_execute_python_code_raw_openpyxl_strips_vba_project.md)）
からの復旧作業（新規xlsm再作成→3シート再構築→VBAモジュール再追加）を
1つのworkerサブエージェントが継続実行し、iter=42（累計82メッセージ）に
達した時点でトークン使用量が閾値（81920）に達し、会話履歴圧縮
（82件→要約1件+直近6件）とトークン閾値注意メッセージの注入が発火した。
圧縮自体は正常に完了し（`会話履歴を圧縮しました`のみでエラー無し）、
その後のタスク継続にも支障は見られなかった。

## ログ引用

```
2026-08-23 11:26:11,239 WARNING src.context_compaction: 会話履歴を圧縮しました: 82件 -> 要約1件 + 直近6件
2026-08-23 11:26:11,239 WARNING src.subagent: subagent: トークン使用量が閾値(81920)に近づいたため注意メッセージを注入(iter=42, total_tokens=82900)
```

## 推定原因

VBAプロジェクト復旧という1タスクの中で、シート再構築を数行～十数行の
`set_cell`/`set_column_width`opsに細かく分割して`execute_python_code`→
`run_script(edit_excel.py)`を繰り返すパターンが続いた（本セッション
11:04〜11:26の間だけで少なくとも10回以上のexecute_python_code呼び出し）。
1回あたりの呼び出し自体は小さいが、シート名の付け替えミス・`row`/`col`
キー誤用（[issue/20260823_111523](20260823_111523_edit_excel_terse_keyerror_message_causes_llm_confusion.md)）
等の失敗による再試行が重なり、iter数・累計メッセージ数を押し上げた。
